# Baby Buddy Planner (Home Assistant Add-on)

Image-only add-on metadata for Home Assistant. Copy this folder into your
add-on repository (e.g. alongside other add-ons) and reference it from
`repository.yaml`.

See [DOCS.md](DOCS.md) for installation and configuration.

The application code and Docker image are built from the parent
[babybuddy-planner](https://github.com/mschnklhn/babybuddy-planner) repository.
